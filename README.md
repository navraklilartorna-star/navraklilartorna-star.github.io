# KODLAMATIC

KODLAMATIC — Engineering & Technologies.

CNC üretim asistanı arayüz prototipi.

## Mevcut durum
Bu sürüm iş emri bilgilerini toplar ve tarayıcıda özetler. Henüz teknik resim geometrisini analiz etmez, takım yolu oluşturmaz, gerçek G-kod üretmez, verileri sunucuya kaydetmez ve CNC tezgâhına bağlanmaz.

Gerçek üretim kodu; geometri, takım yolu, tezgâh/kontrol ünitesi uyumu, çarpışma ve limit kontrolleri ile uzman onayı gerektirir.

## Geliştirme
- npm install
- npm run dev
- npm run build

## Teknoloji
React, TypeScript, Vite. Yayın: GitHub Pages.
